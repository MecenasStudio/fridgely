# Fridgely Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wspólny planer posiłków z lodówką (PL/EN, przeglądarka), z AI na kluczu użytkownika (BYOK).

**Architecture:** SPA React + TS. Czysta logika domenowa w `src/domain` (testowana bez sieci). Supabase: Auth, Postgres z RLS po `household_id`, Realtime. Całe AI przez jedną Edge Function `ai` (wybór klucza, zużycie, limity).

**Tech Stack:** Vite, React 18, TypeScript, Vitest, i18next, @supabase/supabase-js, @dnd-kit/core, Supabase Edge Functions (Deno), Open Food Facts.

**Spec:** `docs/superpowers/specs/2026-10-12-fridgely-design.md`

## Global Constraints

- Interfejs PL i EN, język domyślny z przeglądarki, przełącznik w ustawieniach.
- Klucz AI nigdy w przeglądarce ani w repo; w UI tylko końcówka klucza.
- Data ważności nigdy zgadywana: brak = prośba o uzupełnienie.
- Brak klucza Dawida w aplikacji; wersja 1 = tylko BYOK.
- Produkty bez daty sortowane na końcu listy lodówki.
- Obiad z przeterminowującego się produktu tylko po kliknięciu.
- Open Food Facts nie dostarcza dat ważności.

## Review Focus

- Pusta lodówka i pusta lista przepisów: losowanie i lista zakupów nie mogą się wywrócić, mają pokazać pusty stan.
- Produkt już po terminie: trafia na górę listy i jest oznaczony jako przeterminowany.
- Ta sama pozycja wpisana inaczej ("Mleko" / "mleko "): odejmowanie od listy zakupów ma ją traktować jako jedną.
- Brak klucza AI w koncie: funkcja AI zwraca czytelny błąd, UI prowadzi do ustawień.
- Zdjęcie/kod, którego nie rozpoznano: użytkownik dostaje ręczne dodanie, nie pusty ekran.

### Task 2: Logika domenowa

**Files:**

**Interfaces:**
- Produces:

  - `type Recipe = { id: string; title: string; ingredients: { name: string; quantity: number; unit: string }[]; steps: string[] }`
  - `normalizeName(name: string): string` (trim, lowercase, zwinięte spacje)
  - `sortByExpiry(items: FridgeItem[]): FridgeItem[]` (rosnąco, `null` na końcu, nie mutuje)

  - `pickWeek(recipes: Recipe[], fridge: FridgeItem[], rng: () => number): (Recipe | null)[]` (7 elementów, preferuje przepisy używające najszybciej psującego się produktu, bez powtórzeń gdy przepisów ≥ 7)
